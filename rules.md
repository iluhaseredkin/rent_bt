# Инструкции по деплою на Railway

## Контекст проекта
- Цель: Подготовка Docker-конфигурации для деплоя на Railway.app.
- Метод: Деплой через GitHub репозиторий.

## Правила поведения агента
1. **Docker**: Всегда создавай оптимизированный `Dockerfile` (multi-stage build) и `.dockerignore`.
2. **Git Policy (Строгое ограничение)**: 
   - ТЕБЕ ЗАПРЕЩЕНО выполнять любые команды `git` в терминале (commit, push, remote и т.д.).
   - Вместо выполнения, ты должен вывести в чат текстовый блок с последовательностью команд, которые мне нужно выполнить самостоятельно.
3. **Инструкции**: В конце работы предоставь краткий чеклист действий в панели управления Railway. Общайся на русском языке.
