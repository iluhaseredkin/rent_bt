# Rent Telegram Mini App

Telegram-бот и Mini App для поиска недвижимости в аренду.

## Основные возможности
- **Поиск**: Фильтрация по городам, цене и ключевым словам.
- **Уведомления**: Ежедневные рассылки новых объявлений в бота.
- **Предложения**: Система размещения объявлений пользователями и предложение новых источников.
- **Админка**: Встроенная панель управления (статистика, модерация, управление каналами).

## Быстрый старт

### 1. Требования
- Python 3.10+
- Переменные окружения (см. ниже)

### 2. Установка
```bash
python3 -m venv bt_env
source bt_env/bin/activate
pip install -r requirements.txt
```

### 3. Настройка (.env)
Создайте файл `.env` со следующими параметрами:
- `BOT_TOKEN`: Токен вашего бота.
- `API_ID`, `API_HASH`: Данные с my.telegram.org.
- `TELETHON_SESSION`: Строка сессии Telethon.
- `ADMIN_ID`: ID администраторов (через запятую).

### 4. Запуск
```bash
# Бэкенд и статика
uvicorn app.api:app --reload

# Бот и Парсер
python app/main.py
```

## Админ-панель
Интерфейс админки появляется автоматически в Mini App для пользователей, чей ID указан в `ADMIN_ID`.
В панели доступны:
- Статистика пользователей и каналов.
- Модерация предложенных объявлений и источников.
- **Обслуживание**: кнопки для мгновенного обновления данных в дашборде и ручного запуска парсинга базы.

## Структура проекта
- `app/api.py` - FastAPI сервер.
- `app/bot.py` - Telegram бот (aiogram).
- `app/parser.py` - Логика сбора данных.
- `web_app/` - Статические файлы Mini App (`index.html`, `styles.css`, `app.js`).
