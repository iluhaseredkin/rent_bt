# Telegram Design

Этот скилл предназначен для проектирования современных, функциональных и эстетичных Telegram-ботов и Mini Apps. Он содержит проверенные паттерны архитектуры, рекомендации по UX/UI и технические спецификации.

## Основные этапы проектирования

### 1. Архитектура и структура кода
Для обеспечения масштабируемости используйте модульный подход. Хендлеры должны быть отделены от бизнес-логики.
- См. [bot_architecture.md](references/bot_architecture.md) для подробной структуры проекта и принципов обработки данных.

### 2. Взаимодействие и интерфейс
Качественный бот должен быть интуитивно понятным и отзывчивым.
- **FSM (Конечные автоматы)**: Используйте для пошаговых сценариев (регистрация, создание заказа).
- **Клавиатуры**: Выбирайте Reply для главного меню и Inline для контекстных действий.
- См. [fsm_and_keyboards.md](references/fsm_and_keyboards.md) для лучших практик UI/UX.

### 3. Telegram Mini Apps (TWA)
Когда возможностей обычного чата недостаточно, используйте Mini Apps для создания полноценных веб-интерфейсов.
- **Интеграция**: Использование SDK, темизация под мессенджер, управление нативными кнопками.
- **Безопасность**: Валидация `initData` на бэкенде.
- См. [twa_guidelines.md](references/twa_guidelines.md) для руководства по разработке Mini Apps.

## Полезные советы

- **Логирование и мониторинг**: Всегда логируйте ошибки и важные действия пользователей. Используйте Sentry для отслеживания ошибок в продакшене.
- **Асинхронность**: Telegram API требует асинхронной работы. Избегайте блокирующих вызовов (например, синхронный `requests` или `time.sleep`) в хендлерах.
- **Темизация**: При разработке Mini Apps всегда учитывайте темную и светлую темы Telegram, используя CSS-переменные темы.
