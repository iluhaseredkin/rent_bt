# FSM и Клавиатуры

Эффективное взаимодействие с пользователем строится на правильном управлении состояниями (FSM) и удобных интерфейсах (клавиатурах).

## Finite State Machine (FSM)

FSM используется для создания сценариев диалога (форм, опросов, поэтапной настройки).

### Правила использования FSM:

1.  **Группировка состояний**: Объединяйте связанные состояния в один класс, наследуемый от `StatesGroup`.
    ```python
    class ProfileEdit(StatesGroup):
        name = State()
        age = State()
        city = State()
    ```
2.  **Сброс состояний**: Всегда предусматривайте команду `/cancel` или кнопку "Отмена", которая вызывает `state.clear()`.
3.  **Хранение данных**: Используйте `state.update_data()` для временного хранения ответов пользователя перед сохранением в БД.
4.  **Валидация**: Проверяйте вводимые данные на каждом этапе. Если данные некорректны, отправляйте сообщение с ошибкой и оставайтесь в том же состоянии.

## Клавиатуры (Reply & Inline)

### Reply Keyboards (Обычные кнопки):
- Используются для основного меню.
- Кнопки должны быть краткими (1-2 слова).
- Используйте `resize_keyboard=True` и `one_time_keyboard=False` (обычно).

### Inline Keyboards (Кнопки в сообщениях):
- Используются для динамического взаимодействия, навигации по страницам, выбора опций.
- Всегда подкрепляйте нажатие `callback_query.answer()`, чтобы убрать индикатор загрузки у пользователя.
- Используйте `callback_data` для передачи параметров (например, `user_id:123:edit`).

### UI/UX паттерны:

-   **Пагинация**: Для больших списков используйте инлайн-кнопки "Вперед/Назад" с передачей текущей страницы в `callback_data`.
-   **Подтверждение**: Для деструктивных действий (удаление) всегда запрашивайте подтверждение инлайн-кнопками.
-   **Интерактивные меню**: Обновляйте текущее сообщение (`edit_message_text`) вместо отправки новых, чтобы не засорять историю чата.
-   **Переключение в Mini App**: Используйте кнопку типа `web_app` для бесшовного перехода из чата в Mini App.
